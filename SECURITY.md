# Security policy

**Prototype status:** Neither edition is presented as a production-hardened public game server. The Windows host uses UDP 27960; the browser host uses HTTP/WebSockets on TCP 8080. Neither provides public matchmaking, authentication accounts, or automatic NAT traversal. Do not expose these servers to the open internet unless you accept the risks of running experimental server code.

Please report suspected vulnerabilities privately to the project maintainer using GitHub's private vulnerability reporting feature **if it is enabled** for the repository. Otherwise, avoid posting exploit steps or sensitive details in a public issue; request a private contact route first.
