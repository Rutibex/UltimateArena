# Changelog

## v0.2.0 — Initial public GitHub packaging (2026-11-08)

- Release the **native Windows x64 C# desktop prototype** (application version 0.2.0), including a self-contained Microsoft .NET 8 runtime, bot deathmatch, original procedural graphics/audio, and UDP LAN hosting.
- Include the separately versioned **browser/WebGL + Node.js prototype** (original browser application version 0.1.0), with solo play and WebSocket-hosted matches.
- Supply both sources in organized `desktop/` and `browser/` directories, clean player-ready binary archives, attribution and licensing, setup documentation, issue templates, CI workflow, and release notes.

**Status:** This is a packaging/repository release, not a new verified gameplay implementation. The original Windows binary has not been interactively tested on Windows in the provided verification record.
